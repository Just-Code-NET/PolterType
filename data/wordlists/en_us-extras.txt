# Curated additions to the embedded English dictionary.
#
# `data/wordlists/en_us.txt` comes verbatim from upstream
# (`dwyl/english-words`, see CREDITS.md) and is overwritten when a
# contributor runs `cargo xtask wordlists fetch`. Anything we add
# here lives outside that file so upstream syncs don't clobber it.
#
# `build.rs` merges this list into the en-US FST at compile time,
# so every user gets these out of the box without runtime overlay
# configuration.
#
# Scope: vocabulary that is part of modern technical / online
# English but missing from the general-purpose `dwyl/english-words`
# corpus. Aim for terms a developer or power user is likely to type
# unprefixed and unstyled (no proper-noun capitalisation, no
# product names with weird casing — those go in user overlay).
#
# Format: one lowercase word per line; blank lines and `#`-comments
# ignored.
