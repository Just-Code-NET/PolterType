# PolterType

Кросплатформовий автоматичний перемикач розкладки клавіатури. Працює в
системному треї, помічає, коли ви починаєте друкувати в неправильній розкладці,
перемикає її та повторює останнє слово — ніби доброзичливий полтергейст у вашій
клавіатурі.

Повну документацію, нотатки для розробників і докладні застереження дивіться в
[англійському README](README.md).

В процесі розробки було залучено ШІ.

## Встановлення

Бінарники публікуються на [сторінці Releases](../../releases). Кожен реліз
містить чотири інсталятори:

| Система | Файл | Як встановити |
| --- | --- | --- |
| Windows 10 / 11 | `poltertype-<ver>-x86_64-pc-windows-msvc.msi` | Подвійне натискання. Встановлення для користувача, без прав адміністратора та UAC. SmartScreen може показати «Windows захистив ваш ПК» → **Додатково** → **Виконати все одно**. |
| macOS 11+ (Intel та Apple Silicon) | `poltertype-<ver>-universal-apple-darwin.dmg` | Відкрийте DMG і перетягніть `poltertype.app` у `/Applications`. Під час першого запуску клацніть правою кнопкою → **Відкрити** (або виконайте `xattr -dr com.apple.quarantine /Applications/poltertype.app`). Потім надайте **Спеціальні можливості** та **Моніторинг введення**, коли macOS попросить. Надавати доведеться щоразу після оновлення: без Developer ID macOS упізнає застосунок за хешем його ж байтів, тож нова версія для неї — інша програма. **На Intel беріть 0.14.4 або новішу:** у попередніх DMG зріз x86_64 був непідписаний, а непідписаному коду macOS не дає «Спеціальні можливості» — застосунок працював, дозвіл виглядав наданим, і не виправлялося нічого ([#28](https://github.com/Just-Code-NET/PolterType/issues/28)). |
| Linux (x86_64) | `poltertype-<ver>-x86_64.AppImage` | `chmod +x` і запустіть. Встановлення для користувача, без системного встановлення. Дивіться [docs/PERMISSIONS.md](docs/PERMISSIONS.md) для доступу `evdev` у Wayland. |
| Linux (aarch64) | `poltertype-<ver>-aarch64.AppImage` | Як вище, для ARM64: Raspberry Pi 5, Asahi, ноутбуки та сервери ARM. |

> Інсталятори поки що **не підписані**, тому Gatekeeper або SmartScreen
> попереджають під час першого запуску. Підпис коду з’явиться на пізнішому етапі.

> **Flatpak немає і не буде.** PolterType записує у `/dev/uinput`, на що жоден
> дозвіл Flatpak не дає права, окрім `--device=all` (усе дерево пристроїв), і для
> цього не існує порталу. Перемикання розкладки також потребує системних
> бінарників (`hyprctl`, `gsettings`, `gdbus`, `qdbus`, `ibus`), яких у пісочниці
> немає.
> Аргументацію, джерела й умови, за яких ми переглянемо це рішення, наведено
> в [docs/DECISIONS.md](docs/DECISIONS.md) (2026-07-31). Використовуйте
> AppImage або нативний пакет.
